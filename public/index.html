1 Architecture & Core Concepts

🔄

Internal Modifications

Cheat code is directly saved in the game's static files space. Injected into the process — easier detection but full access to game internals.

📡

External Modifications

Sit separately from the game and use Windows API features (or kernel drivers) to read/write memory data. Harder to detect, but limited to memory operations.

💡
Server-Side Limits: Damage calculation, loot distribution, and physics are validated server-side. External tools cannot bypass authoritative mechanics.
⚡
Unity-Specific: Mono/IL2CPP structure, managed object layouts, and native-to-managed bridges require offset translation.

Step 1: Professional Panel UI Development

Build a modern, visually appealing panel UI for your desktop application.

❓ Why does the UI matter? Isn't it just about functionality? ▼
A good UI improves usability, reduces errors, and makes your tool professional. While functionality is king, a clean interface helps you navigate features quickly. It also matters for distribution — people trust polished software.
❓ Should I use GUI or TUI? ▼
It depends on your use case. GUI (ImGui, Qt, WinForms) is better for visual overlays and user-friendly panels. TUI (Spectre.Console, ncurses) is great for headless servers or quick tools. Many devs use both — TUI for backend/debug and GUI for the main panel.
❓ What if I want to skip UI entirely? ▼
You absolutely can! A console application that runs silently in the background is perfectly valid. This step is here for those who want it — skip to Step 2 if UI isn't your priority.

Qt Framework GUI Application

Cross-platform desktop application with login system and main UI panel. Alternative: ImGui.

🛠️ Tools & Libraries

Qt Creator (or VS + Qt tools) • Qt Widgets Module • Qt Designer (.ui files) • QSS (Qt Style Sheets)

Implementation Steps

  1. Install Qt and Qt Creator. Create a new Qt Widgets Application project.
  2. Design the Login Dialog: Use QDialog, add QLineEdit for username/password, QPushButton for login.
  3. In the login logic, check credentials. Emit accepted() signal upon success.
  4. Create the Main Window (QMainWindow) with QStackedWidget for multi-page content.
  5. Apply modern style sheets: border-radius on buttons, background gradients, hover effects.
  6. After successful login, hide the login dialog and show the main window.
  7. Implement main UI panels: dashboard with QChart/QTableView, side menu with categories.
  8. Use layouts (QVBoxLayout, QHBoxLayout, QGridLayout) to organize controls.
  9. Add dynamic content switching: connect menu buttons to change central widget index on QStackedWidget.
  10. Handle shutdown, save preferences, add window animations (QPropertyAnimation).

🔗 Attaching Buttons & UI to Code (Event Wiring)

Method 1: Qt Designer (No Code)

Open your .ui file in Qt Designer → Right-click a button → "Go to slot…" → Select clicked() → Qt auto-generates the slot function. Just fill in the logic.

Method 2: Manual connect()

C++ — Signal/Slot Connection
// In constructor after setupUi:
connect(ui->btnAimbot, &QPushButton::clicked, this, [&]() {
    aimbotEnabled = !aimbotEnabled;
    ui->btnAimbot->setText(aimbotEnabled ? "Aimbot: ON" : "Aimbot: OFF");
    ui->btnAimbot->setStyleSheet(aimbotEnabled ? "background-color: #16A34A;" : "background-color: #DC2626;");
});

// Slider to value label
connect(ui->fovSlider, &QSlider::valueChanged, this, [&](int val) {
    ui->fovLabel->setText("FOV: " + QString::number(val));
    config.fov = val;
});
✨
Design Tip: Use QSS for modern flat UI. Example: QPushButton { background-color: #3498db; border-radius: 5px; padding: 8px; } QPushButton:hover { background-color: #2980b9; }. Add shadows with QGraphicsDropShadowEffect.

🔗 Attaching Buttons & UI to Code (Event Wiring)

Method 1: Double-Click (Fastest)

In the Visual Studio Designer, double-click any button. VS auto-generates a click event handler. Just write your logic inside.

Method 2: Properties Panel → Events Tab

Select a control → In Properties, click the ⚡ lightning bolt → Find the event (e.g., Click) → Double-click to generate handler.

Method 3: Manual Code Wiring

C# — Manual Event Subscription
// In constructor after InitializeComponent():
btnAimbot.Click += BtnAimbot_Click;
fovSlider.ValueChanged += FovSlider_Changed;

private void BtnAimbot_Click(object sender, EventArgs e)
{
    aimbotEnabled = !aimbotEnabled;
    btnAimbot.Text = aimbotEnabled ? "Aimbot: ON" : "Aimbot: OFF";
    btnAimbot.FillColor = aimbotEnabled ? Color.FromArgb(22, 163, 74) : Color.FromArgb(220, 38, 38);
}

Method 4: Lambda (Inline, Quick)

C# — Lambda Event Handlers
btnRefresh.Click += (s, e) => RefreshOffsets();
btnSave.Click += (s, e) => {
    config.Save("config.json");
    MessageBox.Show("Config saved!");
};

📋 Key Takeaways — Step 1

  • UI is optional but recommended for usability and professionalism
  • C++/Qt: Use Signals & Slots to wire UI → code. Methods: Designer, manual connect(), lambdas
  • C#/WinForms: Use Event Handlers. Methods: Double-click, Properties Events tab, manual +=, lambdas
  • C#/Spectre.Console: Use SelectionPrompt and TextPrompt for TUI interactivity
  • Separate UI logic from business logic (MVVM/MVC pattern)
